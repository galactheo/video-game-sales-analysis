# Video Game Sales Analysis
An exploratory analysis of video game sales through 2016, completed as part of the TripleTen Data Science bootcamp.
The case study uses data available through 2016 to explore which games, platforms, and genres might be promising for a hypothetical marketing campaign in 2017.

### Project Overview
The analysis focuses on:
- Cleaning and preparing game sales data, including missing values and inconsistent types.
- Examining platform lifecycles and sales trends over time.
- Comparing video game preferences across North America, Europe, and Japan.
- Investigating relationships between user/critic reviews and global sales.
- Testing hypotheses about user ratings across platforms and genres using statistical tests.

**🛠️ Tools:** Python, Pandas, NumPy, Matplotlib, SciPy

### Key Findings
- Platform popularity changes over time, making recent sales trends more relevant to planning.
- Sales distributions are highly skewed: a small number of titles account for exceptionally high sales.
- Regional preferences vary, especially in platform and genre popularity.
- Critic scores show a moderate positive correlation with PS4 game sales in the analyzed sample; correlation does not establish causation.
- Welch’s T-tests do not find a statistically significant mean user-score difference between Xbox One and PC games, but do find one between Action and Sports games.

**Note:** This is a historical educational case study, not an analysis of today's gaming market.
